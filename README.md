# LED Music

Светомузыка и управление для Bluetooth LED-лент **ELK-BLEDOM / ELK-BLEDDM** с компьютера на Windows и с iPhone.

## Возможности

**Программа для Windows** (`start.bat`):

- ручной цвет, яркость, вкл/выкл;
- светомузыка из звука компьютера (Spotify и любой плеер):
  - **Частоты** — басы тёплые, верха холодные, бочка вспыхивает, хай-хэты искрят;
  - **Бит** — новый цвет на каждый удар;
  - **Такт** — цвет меняется строго в темп песни (темп определяется автоматически);
  - **Пульс** — яркость от басов;
  - **Плавный** — спокойное «дыхание» без вспышек;
  - **Свой** — настраивается ползунками: скорость, сила вспышек, яркость, искры;
  - **Спектр** — басы/середина/верха = R/G/B;
- **Экран** — лента повторяет цвет того, что на мониторе;
- эффекты без музыки: **свеча, камин, гроза, мигалка, северное сияние**;
- 7 палитр + **«Обложка трека»**: цвета берутся из обложки песни, которая играет в Spotify;
- смена палитры на припеве, стробоскоп на дропах (по желанию);
- будильник-рассвет и таймер сна;
- трей, автозапуск с Windows, горячие клавиши:
  - `Ctrl+Alt+L` — вкл/выкл;
  - `Ctrl+Alt+M` — режим;
  - `Ctrl+Alt+P` — палитра;
  - `Ctrl+Alt+↑/↓` — яркость;
- порядок цветов ленты (RGB, GRB, …) — если красный горит зелёным.

**Приложение для iPhone** (`docs/index.html`, публикуется через GitHub Pages): цвет, яркость, режимы и палитры, светомузыка через микрофон. Открывать в браузере **Bluefy** (Safari не поддерживает Bluetooth).

## Установка на Windows

1. Установите [Python 3.12+](https://www.python.org/downloads/) (галочка «Add to PATH»).
2. Запустите `install.bat`.
3. Запустите `start.bat`.

Адрес ленты задаётся в `protocol.py` (`DEFAULT_ADDRESS`). Найти его можно в любом BLE-сканере: имя ленты начинается с `ELK-`.

## Как устроено

| Файл | Что делает |
|------|------------|
| `led_gui.py` | окно, трей, горячие клавиши |
| `engine.py` | настройки, будильник, таймер сна, связь с лентой |
| `effects.py` | световые режимы |
| `audio.py` | захват звука, поиск бита, хай-хэтов и дропов |
| `rhythm.py` | темп песни (BPM) и поиск припева |
| `sources.py` | палитра из обложки Spotify, цвет экрана |
| `palettes.py` | палитры |
| `protocol.py` | Bluetooth-команды ленты |
| `led_music.py` | версия без окна (`start_console.bat --help`) |
| `docs/index.html` | приложение для iPhone |

Проверки: `python test_features.py`, `test_modes.py`, `test_rhythm.py`, `test_palettes.py`, `test_fire.py`, `test_freq.py`, `test_beats.py`.
